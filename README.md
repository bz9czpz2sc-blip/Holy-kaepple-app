# Holy Käpple – App-Prototyp

Ein erster funktionierender Mobile-Prototyp der Holy-Käpple VfB-Fanclub-App.

## Enthalten
- Startseite mit News
- Heimspielübersicht
- Termine & Events
- Ticketbörse als erster Entwurf
- Adminbereich als UI-Prototyp
- Responsive Mobile-Design
- VfB-inspirierte rot/weiß/schwarze Optik

## Start
`index.html` auf einem Smartphone oder Computer im Browser öffnen.

Hinweis: Die Daten sind aktuell Beispieldaten. Für die echte App brauchen wir im nächsten Schritt eine Datenbank, Mitglieder-Login, echte VfB-Spielplandaten und eine saubere Rechteverwaltung für den Adminbereich.
